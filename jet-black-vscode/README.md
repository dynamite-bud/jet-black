# Jet Black — VS Code

A pure-black dark theme. Open the Command Palette → **Color Theme** → **Jet Black**.

Part of the [jet-black](https://github.com/rudra/jet-black) multi-tool palette — the same colors theme your terminal (ghostty), tmux, and starship.

The theme JSON is generated from `schemes/jet-black.yaml` via tinted-theming; don't edit `themes/*.json` by hand — edit the scheme and run `./build.sh`.

Derived from [Pitch Black](https://github.com/ViktorQvarfordt/vscode-pitch-black-theme) (© 2021 Viktor Qvarfordt, MIT).
